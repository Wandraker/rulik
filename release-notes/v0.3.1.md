Ровный стрим / Smooth streaming.

**ПК**
- Экран снимается через Windows Graphics Capture: кадры приходят ровно, без рывков и «догона»
- Картинку 1080p/720p/480p уменьшает видеокарта, а не процессор
- Частота стрима не выше частоты монитора, поэтому весь битрейт идёт на настоящие кадры
- Исправлена ошибка: окно сервера не всегда обновляло список сетей (русские названия сетей ломали разбор)

**Телефон**
- Декодер в режиме низкой задержки на любых чипах. На MediaTek выключена постобработка видео MIUI/HyperOS. Декодирование 6–12 мс вместо 20–30
- Кадры, пришедшие пачкой, не проигрываются ускоренно: сразу показывается самый свежий
- По кабелю через adb видео идёт отдельным соединением, кнопки и пинг больше его не ждут
- Во время игры экран переключается на 90/120 Гц, а Wi-Fi держится в режиме низкой задержки
- В строке статистики виден декодер

---

**PC**
- The screen is captured with Windows Graphics Capture: frames arrive evenly, without stutter or catch-up bursts
- 1080p/720p/480p scaling runs on the graphics card instead of the processor
- The stream never runs faster than the monitor, so the whole bitrate goes to real frames
- Fixed: the server window didn't always refresh the network list (non-English network names broke parsing)

**Phone**
- The decoder runs in low-latency mode on any chip. On MediaTek, MIUI/HyperOS video post-processing is turned off. Decoding takes 6–12 ms instead of 20–30
- Frames that arrive in a bunch no longer play in fast-forward: the newest one is shown right away
- Over an adb cable, video uses its own connection, so buttons and ping no longer wait behind it
- While you play, the screen switches to 90/120 Hz and Wi-Fi stays in low-latency mode
- The stats line shows the decoder

Update both `rulik.apk` on the phone and `rulik-server.exe` on the PC.
