Первая версия Rulik / First Rulik release.

**Телефон (Android 10+)**
- Геймпад Xbox, мышь и клавиатура по Wi-Fi или USB
- Шесть готовых раскладок и редактор: кнопки, стики, крестовины, тачпад
- Гироприцел, руль наклоном, вибрация из игры
- Поиск ПК в сети, PIN, автоподключение

**ПК (Windows 10/11)**
- Виртуальный геймпад для каждого телефона через ViGEmBus
- Установка драйвера и правило брандмауэра в один клик
- USB через `adb reverse`

---

**Phone (Android 10+)**
- Xbox gamepad, mouse and keyboard over Wi-Fi or USB
- Six built-in layouts and an editor: buttons, sticks, D-pads, touchpad
- Gyro aiming, tilt steering, game rumble
- PC discovery, PIN, auto-reconnect

**PC (Windows 10/11)**
- A virtual gamepad per phone through ViGEmBus
- One-click driver install and firewall rule
- USB through `adb reverse`

Download `rulik.apk` for the phone and `rulik-server.exe` for the PC.
