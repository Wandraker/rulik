FAQ

Which games does it work with?

Any game you can play with an Xbox gamepad or with mouse and keyboard. Rulik creates a real virtual controller in the system, so it doesn't matter where the game came from: Steam, Epic, GOG, the Xbox app, a disc or anywhere else.

Why the ViGEmBus driver?

Without a driver, Windows doesn't let a program create a gamepad. ViGEmBus is used by DS4Windows, Steam Input and many emulators. It ships inside Rulik Server and installs with one button.

How much latency?

On home Wi-Fi it's usually 2–10 ms one way, and even less over USB tethering. Packets are tiny and go over UDP with no extra round trips. If a packet gets lost, the phone resends the full state four times a second, so a button never gets stuck.

Can two people play?

Yes. Every connected phone gets its own gamepad, up to 8 devices per PC. Great for split-screen games.

Will anti-cheat ban me?

Rulik provides a normal virtual gamepad and normal Windows input, and injects nothing into games. Most games accept that without issue. Some competitive anti-cheats block virtual devices or emulated input, and then Rulik won't work in that game. Check the rules of the specific game.

Is it safe? Can anyone on the network control my PC?

No: by default the server asks for a PIN that only shows up in its window. You can change the PIN at any time, and "Disconnect all" kicks every phone right away. The server only accepts control input and gives no access to files.

What about iPhone, macOS, Linux?

Android and Windows only for now. The protocol is open and documented in the repository, so ports to other systems are possible.

How much does it cost?

Nothing. The code is open under the GPL-3.0 license: you can study and improve it, but any version based on it must stay open source too. github.com/Wandraker/rulik.
