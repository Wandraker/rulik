You need two parts: the app for your phone and the program for your PC. Both are free, with no ads and no sign-up.

latest version
  • Android 10 or newer
  • About 3 MB
  • When installing, allow "Install from this source"
Download rulik.apk

{{icon:pc}}Rulik Server for Windows

latest version
  • Windows 10 and 11, 64-bit
  • No installation, just run it
  • The gamepad needs the ViGEmBus driver, and the server offers to install it for you
Download rulik-server.exe

Next

Start the server on your PC, open the app and follow the connection guide. If Windows SmartScreen warns about an unknown publisher, click "More info" and "Run anyway": the project doesn't have a paid code signing certificate yet.

All versions and changelogs: releases on GitHub. The source code is open, so you can build it yourself.
